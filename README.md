Number Guessing Game
A simple Python number guessing game where the computer chooses a number from 0 to 5.

About
In this game, the computer randomly chooses a number between 0 and 5, and the player tries to guess the number.

This project was created to practice random number generation, user input, variables, and conditional statements.

How It Works
The computer randomly chooses a number between 0 and 5.

The player enters a guess.

The program compares the guess with the number chosen by the computer.

The program tells the player whether the guess was correct or incorrect.

Technologies

random module

How to Run
Clone the repository:

git clone https://github.com/YOUR-USERNAME/number-guessing-game.git

Enter the project folder:

cd number-guessing-game

Run the program:

python main.py
